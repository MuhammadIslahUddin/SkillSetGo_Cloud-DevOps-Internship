1. What is Cloud Computing?
====================================
Cloud computing means using computers, storage, and networks that are provided by companies like Microsoft (Azure) or Amazon (AWS) over the internet, instead of buying your own physical servers.

====================================
2. Three Main Building Blocks
====================================

A. Compute
- This is the "brain" or the computer itself.
- In Azure: Virtual Machines (VMs), App Services, Azure Functions
- Example: Running a website or an application

B. Storage
- This is where you keep files, pictures, databases, and backups.
- In Azure: Storage Accounts, Blob Storage, Disk Storage
- Example: Storing images or website files

C. Networking
- This connects everything together and to the internet.
- In Azure: Virtual Network (VNet), Public IP Address, Load Balancer, Network Security Group
- Example: Allowing people to visit your website from the internet
